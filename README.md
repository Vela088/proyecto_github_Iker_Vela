PROYECTO GIT Y GITHUB DE IKER Y ADRIÁN

📌 Descripción del proyecto:

Este proyecto consiste en la creación de una página web dedicada al Mundial de Fútbol 2026.

El objetivo es ofrecer una web sencilla en la que los usuarios puedan consultar información sobre algunos de los equipos participantes y visualizar una tabla con resultados de partidos de ejemplo.

Además, este proyecto nos permite poner en práctica los conocimientos adquiridos sobre control de versiones y trabajo colaborativo utilizando Git, GitHub y Trello.

🌍 Contenido de la web

La página web está dividida en tres secciones principales:

Inicio (index.html): página principal donde presentamos el proyecto y explicamos su funcionamiento.

Equipos (equipos.html): muestra información sobre cuatro selecciones nacionales: España, Argentina, Brasil y Francia.

Partidos (partidos.html): contiene una tabla con algunos resultados de partidos de ejemplo.

🛠️ Tecnologías utilizadas

HTML5: estructura de las páginas web.

CSS3: diseño, colores, fondos y estilos.

JavaScript: funcionalidades e interactividad.

Git: control de versiones.

GitHub: alojamiento del repositorio y colaboración.

Trello: organización y reparto de tareas.
